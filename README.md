# SL - Carreras
Pagina web se podrá consultar carreras, inscripciones y formularios.
Incluye imagenes, html, css y js.

# Uso
1. Abrir la pagina web.
2. vas a poder navegar desde la barra de navegación, inicio, carreras y formulario.
3. completar el formulario y revisar si salio correctamente como habilitado
